# ReviewOS

An open source, self-hostable git forge built around code review.

Most forges treat review as a tab on a pull request. Here it is the primary
object, and the rest of the forge exists to serve it: threads that follow a
line through a rebase, stacked pull requests that merge in order, and diffs
rendered on the server so a hundred files stay readable.

This instance runs the forge on one box, against its own Postgres, and hosts
the project's own code as its first repository.
